# Política de privacidad — El Negocio Invisible (herramienta de publicación)

**Última actualización:** 26 de noviembre de 2026

## 1. Quiénes somos

«El Negocio Invisible» es un canal de YouTube de documentales sobre negocios y empresas. Para gestionar las publicaciones del propio canal usamos una herramienta interna, también llamada «El Negocio Invisible», que se conecta a YouTube mediante la API oficial de YouTube (YouTube Data API v3).

Esta herramienta es de uso privado: solo la usa el titular del canal para gestionar su propia cuenta. No se ofrece al público ni a terceros.

**Contacto:** lesteraac@gmail.com

## 2. Qué datos usa la herramienta

Cuando el titular del canal autoriza la herramienta con su cuenta de Google, esta solicita únicamente los permisos necesarios para:

- subir vídeos al canal;
- añadir o actualizar el título, la descripción, las etiquetas, la miniatura y los subtítulos de esos vídeos;
- programar la fecha de publicación y consultar el estado de los vídeos subidos (procesamiento y visibilidad);
- comprobar en qué canal de YouTube se ha iniciado sesión, para no publicar por error en otro.

La herramienta **no** accede a los datos de los espectadores, a los comentarios, a los mensajes ni a la información de pago, y no lee contenido de otros canales.

## 3. Dónde se guardan los datos

- El token de acceso que entrega Google se guarda **solo en el ordenador del titular del canal**, en un archivo local que no se publica ni se comparte.
- Los vídeos, miniaturas, subtítulos y textos se crean en ese mismo ordenador y se envían directamente a YouTube.
- La herramienta no tiene servidores propios ni bases de datos externas, y no guarda copias de los datos de YouTube fuera de ese ordenador.

## 4. Con quién se comparten

Con nadie. Los datos obtenidos a través de las API de Google no se venden, no se ceden a terceros y no se usan con fines publicitarios. Solo se envían a YouTube para realizar las acciones descritas en el punto 2.

El uso que hace esta herramienta de la información recibida de las API de Google cumple la [Política de datos de usuario de los servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de uso limitado. También se rige por las [Condiciones del Servicio de YouTube](https://www.youtube.com/t/terms) y la [Política de privacidad de Google](https://policies.google.com/privacy).

## 5. Cuánto tiempo se conservan

El token de acceso se conserva mientras el titular del canal mantenga la autorización. Se elimina borrando el archivo local o revocando el acceso.

## 6. Cómo revocar el acceso

En cualquier momento se puede retirar el permiso desde la página de seguridad de la cuenta de Google: <https://myaccount.google.com/permissions>. Al revocarlo, la herramienta deja de poder actuar sobre el canal de inmediato.

## 7. Cambios en esta política

Si la herramienta cambia lo que hace con los datos, se actualizará esta página y su fecha.
